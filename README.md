# PageRankによる棋士のランキング
## 概要
- 将棋の公式戦対局結果から各棋士のPageRankを算出した。
- 各年度に活躍した棋士を適切に抽出できている気がする。ただし改善の余地あり

## 手法
PageRankはGoogleの検索エンジンに採用されて有名になったアルゴリズムである。Webページ間に張られているハイパーリンクのネットワーク構造から各Webページの重要度を計算する手法であり、
   - 多くのページからリンクされているページは価値が高い
   - 価値の高いページからリンクされているページは価値が高い

という考え方に基づいて設計されている。

ところで、PageRankはスポーツ等のプレイヤーのランキングに利用することも可能である。そのためには、各プレイヤーをWebページに、試合結果を敗者から勝者へのハイパーリンクに見立てればよい。多くの勝星、あるいは強い相手からの勝星を集めたプレイヤーがPageRankの上位に来るであろう。この手法については[^1]が詳しい。 

今回は将棋棋士についてPageRankを計算してみる。具体的な手順は以下の通り。

1. [日本将棋連盟の対局結果ページ][1]から、2006年度から2025年度までの各年度の対局結果HTMLを取得した。
2. Beautiful Soupを用いてHTMLから「対局日」「対局者」「勝敗」の情報を抽出した。抽出したデータは、年度ごとに独立したCSVファイルとして整理した。
3. NetworkXライブラリを用い、年度ごとに個別の有向グラフを作成してPageRankを算出した。
   - **ノード**: 各棋士をノードとした。
   - **エッジ**: 敗者から勝者へ向かう向きにエッジを張った。同一年度内に同じカードで複数回対局がある場合、勝利数を重みとして反映させるため、その回数分だけエッジを張った。

グラフの作成にあたっては、棋士同士の対局のみを考慮した。対局者に女流棋士、奨励会員、アマチュアが含まれる対局は除外した。PageRankのダンピングファクターは標準的な値である $\alpha = 0.85$ とした。**連盟HPに結果が掲載されないNHK杯および銀河戦の結果は反映されていない。**

## PageRankは活躍度指標として適切か？
上記のランキングは筆者（将棋ファン）の主観ではかなり的確に感じる。ただし、PageRankを活躍度指標として活用するには様々なことを考えなければならない。

#### ダンピングファクター
ランキングはダンピングファクター$ \alpha $に依存する。例えば2025年度において$ \alpha = 0.5 $とした場合、ランキングは

| 順位 | 棋士名 | PageRankスコア |
|------|--------|----------------|
| 1 | 伊藤匠 | 0.015140 |
| 2 | 永瀬拓矢 | 0.014810 |
| 3 | 藤井聡太 | 0.011874 |
| 4 | 吉池隆真 | 0.010590 |
| 5 | 古賀悠聖 | 0.010207 |

のように変動する。適切な$ \alpha $の値がいくつであるかは調整が要る。$ \alpha $の設定には評価者の恣意が入るため、例えば将棋大賞の選定にPageRankを用いるのは注意が必要である。

#### 数理的な挙動
筆者の勉強不足のため、PageRankが定性的にどんな挙動をするのか掴めていないところがある。例えば、タイトル戦の番勝負でストレート勝ちするのとフルセットまで持ち込まれて勝つのとではどちらがどれだけ良いのだろうか。PageRankの値はネットワーク全体の構造から定まるので、プレイヤーの一勝がどれだけ価値を持つのか簡単には解析できない。追って研究したい。

#### 対局者側から見てどうか
対局者から見た場合指標としてどう映るのだろうか。

PageRankのひとつの特徴は、対局の背景を考慮しないことである。数理的には名人戦七番勝負の第七局と新人王戦の一回戦はまったく同等に扱われる。この点は対局者の心理には反するのではないか。もっとも、タイトル戦の挑戦者は予選を勝ち抜いているためその時点で高いPageRankを保有している可能性が高く、一局の価値は前者の方が高くなる傾向にある。

また、はっきり確かめていないことだが、おそらくPageRankは敗北に対して鈍感な指標である。たとえば2006藤井猛の成績はスクレイピングで取得した限りでは12勝20敗であるが、PageRankでは14位にランクインしている。これは2006年の藤井が強い相手と頻繁に対戦し、負け越しながらも実は価値ある勝利を積み重ねていたことを示している。このように、PageRankは「強い相手に勝てば上がる」ため、ある意味で夢のある指標かもしれない。

## まとめ
この記事ではPageRankを棋士のランキングに適用した。現状、ダンピングファクターの問題があり、また筆者には数理的にわからない部分も多く道半ばといった感じである。とはいえPageRankの計算は楽しく新たな発見も多かった（個人的に印象に残った棋士成績は2006佐藤康光（1位）、2006藤井猛（14位）、2016千田翔太（1位）、2017藤井聡太（1位）、2020飯島栄治（8位）など）。将棋界を新たな目で見る指標としてPageRankを育てられれば嬉しい。

## 備考
### 女流棋士、奨励会員、アマチュアの除外
今回の分析ではいわゆる正棋士同士の対局のみで部分グラフを作成した。女流棋士、奨励会員、アマチュアも含めた全対局結果から単にPageRankを計算することも可能だが、次の点に留意が必要である。

- 対局結果の取得の問題。現在の実装では、対局者の情報を得るために、対局結果のページのhtmlに記載されている棋士ページへのハイパーリンクを使用している。このハイパーリンクが切れている場合対局者の情報を得ることができない。奨励会員、アマチュア、LPSA所属の女流棋士にはハイパーリンクが貼られていない。（氏名を対局者識別のIDとする方法も考えられるが、改姓や表記揺れの問題がある。）

- 奨励会員やアマチュアは参加棋戦が限られているため自然と負け数が少なくなる。PageRankは負け数の少ない棋士からの勝利を高く評価するため、奨励会員やアマチュアからの勝利の価値が過剰に高くなる。（この事象は新人王戦や加古川青流戦で起こりやすい。筆者は「加古川問題」と呼んでいる）

- 女流棋士のトップ層は女流棋戦で多くのPageRankを稼ぐため、女流棋士からの勝利は同等の実力の正棋士からの勝利よりも価値が高くなる。

以上の問題のため今回の分析では正棋士以外を除外した。もっとも、近年では女流棋士、奨励会員が勝ち上がるケースが増えているし、彼ら彼女らもまた将棋界を構成する一員であるので、できれば分析対象を広げたいと望んでいる。
